# Phase 16 — 1-to-1 Voice Calling

Status: IMPLEMENTED IN REPOSITORY — LIVE CALL VERIFICATION PENDING

Implemented:
- Call-start and call-accept requests use authenticated backend APIs and short-lived LiveKit credentials generated by the server.
- Existing call screen now tracks connection state and elapsed connected time.
- Mute/unmute updates the LiveKit local microphone state and reports failure instead of silently changing the UI.
- Audio output can switch between earpiece and speaker, with Bluetooth and wired communication routes exposed when Android reports them.
- Ending a call attempts backend state cleanup, disconnects LiveKit, and closes the associated Telecom connection.
- Microphone permission denial is visible and can be retried from the call screen.
