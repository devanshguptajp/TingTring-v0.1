# TingTring Talk Backend

Phase 5 backend foundation.

## Run

```
npm install
npm run check
npm start
```

Endpoints:
- GET /health
- GET /api/v1
- GET /api/v1/health

Phase 5 intentionally does not implement authentication, users, database schema, calls, LiveKit tokens, or payments.

The Supabase service-role key is server-only and must never be placed in the Android app.
